# Social Cognition Lab website

Static site for www.uncgsocialcognition.com, hosted on GitHub Pages.

## Pages

| File | Page |
|---|---|
| index.html | Home |
| research.html | Research |
| team.html | Team |
| publications.html | Publications |
| news.html | What we're up to |
| lab-inception.html | Lab inception |
| join.html | Join us |
| contact.html | Contact |

The folders `lab-members`, `on-the-move`, `general-1`, `join-the-lab` and `contact-us` only redirect the old Wix addresses to the new pages. `CNAME` tells GitHub Pages to use www.uncgsocialcognition.com.

## Photos and PDFs

Lab photos, headshots, event photos, publication PDFs still load from Wix's file servers (static.wixstatic.com and usrfiles.com). Keep the Wix site in your account, even on the free plan, so those files stay online. Site graphics such as the banner, the faces image and the research figures are in `images/`.

## Making edits

Open a file on github.com, click the pencil icon, edit, and click **Commit changes**. The live site updates within a minute or two.

## Visitor analytics

Every page loads a small GoatCounter script (just before `</head>`) that counts visits without cookies. See visitors, countries, pages, referrers, and devices at https://britcass.goatcounter.com (sign in with the account created for it). Bots and your own visits from a browser where you've told GoatCounter to ignore you are not counted. New pages should copy the same `<script data-goatcounter=...>` line.
The CV is in `files/Cassidy_CV.pdf`; replace that file (same name) to update the Download CV link on the Team page.
